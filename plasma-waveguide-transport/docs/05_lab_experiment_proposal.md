# Lab Experiment Proposal

### Objective
Demonstrate:
- Guided whistler-mode propagation
- Stable plasma channel formation
- MeV-scale particle acceleration
- Over **1 meter**

### Experimental Parameters

| Parameter | Value |
|--------|------|
| Plasma density | $10^{18}\,\mathrm{m^{-3}}$ |
| Magnetic field | 0.5–1 T |
| Frequency | 0.5–2 GHz |
| Laser intensity | $10^{14}–10^{15}\,\mathrm{W/cm^2}$ |
| Channel length | 1 m |

### Diagnostics
- Interferometry (density profile)
- Spectroscopy (temperature)
- Electron spectrometer (energy gain)

### Budget (Order of Magnitude)
- Laser system: \$50k
- Vacuum chamber: \$20k
- Diagnostics: \$30k
- Labor: \$40k
**Total:** \$140k
