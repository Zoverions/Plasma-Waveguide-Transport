# Channel Formation Physics

### Ponderomotive Channel Condition

A plasma channel self‑forms when:

\[
\frac{\epsilon_0 E_0^2}{4} > n_e k_B T_e
\]

This creates a **density depression** that guides waves and particles.

### Wakefield Acceleration Gradient

\[
E_{\text{wake}} \sim \frac{m_e c \omega_p}{e}
\]

This is the same physics used in:
- SLAC laser wakefield accelerators
- CERN plasma acceleration experiments
