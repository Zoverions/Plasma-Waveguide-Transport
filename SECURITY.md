# Security policy

## Supported scope

Security fixes are prepared against the current default branch and reviewed through pull requests. This repository is a computational research prototype; no hardware, control system, live service, or deployed transport system is supported.

## Report a vulnerability privately

Use this repository's **Security** tab to open a private vulnerability report. Include the affected commit or file, reproduction steps, impact, and any safe proof of concept needed to understand the issue.

Do not open a public issue for an unpatched vulnerability. Do not include live credentials, personal data, or sensitive system details in public discussions.

## Response boundary

A report will be assessed against the documented computational scope. Receiving or fixing a report does not establish laboratory validation, engineering feasibility, device safety, or deployment readiness.
